# S0a 运营方档案（AI 主动索取 → 本地回落）

```text
【公司资料建档 · 可选】
为了以后不用重复问，可将公司资料存本机：
1. 公司名：<可跳过>
2. 官网 / 产品页 / 目录：<选填，有则提炼资料>
3. 联系邮箱：<可跳过>
4. 目标市场 / 邮件语言：<可跳过>
选填步骤，想跳过回「跳过」，不影响后续。
您发完之后：我接着核对产品资料。
该回什么：回复资料内容，或回「跳过」。
```

## AI 执行要点与边界

- **展示时机**：首次安装默认不主动弹本卡（避免多占一轮回复）；仅当用户主动提供公司名/官网/邮箱，或换产品/换机复用时展示
- 本轮只问公司级资料，不与 ABCD 方向选择或产品8字段确认挤在同一轮；给默认可跳过、不逼问
- 首次先 `operator_profile.py init --operator-key <固定标识> --nickname <纯昵称>`，再用 `update` 回落用户提供字段；已有非空字段不重复索取
- 用户给网址时先按 `specs/website-profile-sop.md` 确认角色：自己的网址才进独立网站模块；买家网址转 S3；第三方参考只分析
- 网站模块只生成候选，按 `S0a-website-profile.md` 展示并经用户批准后才导入；失败/跳过不阻断原流程，不修改线上网站
- 公司名/官网/联系邮箱/默认市场与语言存 `.local/operators/<operator_key>.md`；认证/产能/MOQ/交期/价格带存当前产品的 product-profile
- token、潜在买家/客户/联系人第三方资料不进入运营方档案
- 邮件末尾签名区只读取 nickname，禁止公司名/官网/邮箱/职位/认证或宣传语
