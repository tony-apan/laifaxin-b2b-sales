# 输出模板总索引（AI 照此执行与展示）

> **给任何 AI 的使用说明**：每个流程节点该对用户说什么、怎么说、什么不能说——**照对应模板填充 `<占位符>` 输出**，不要自由发挥。每个模板 = ①用户话术（代码块内）+ ②AI 执行要点与边界（要点/规则/边界任一标题）。

## 全局规则（每个模板都隐含，违反即错）

0. **★对用户开口的任何时刻都禁工具名/行话，失败必给唯一下一步（2026-09-11 用户实测拍板）**：成功、失败、停下、异常、等待都算；禁止出现 `.py`/`.sh` 文件名、退出码、`[PASS]`/`[FAIL]`、`落点`/`凭据` 等内部词。未通过时三段式：①哪一步没成+**是不是您的问题**（多数是流程没走完或平台临时问题，必须说明白）②**您现在要做的一件事**（没有就说"您什么都不用做"）③本次没动您的数据。照 `S0-connect-failed.md`；工具原始输出只给自己看。
0b. **★菜单/选项：逐行 + emoji + 标 ⭐推荐 + 上限 4 项（2026-09-10 用户拍板）**：任何给用户选的任务菜单/选项列表，**逐项独立成行**、每项前加 emoji、明确标注推荐项，且**项数上限 4 并按状态裁剪**（只放当前状态可用的动作）。**禁止**把编号压成 `①②③` 连成一行（用户反馈"1234 不明显"）；**禁止**列出不适用项（如新用户看到"继续项目（无）" → 选择困难）。聊天话术鼓励 emoji；**邮件正文**另有禁 emoji 规则（`specs/sequence-config.md`），两处不混用。

1. **渐进索取**：每步只问当前必需的一件事；安装过门后先连平台（复用已验证会话，否则专用浏览器自动连接，人工复制仅环境失败兜底）；连接成功后一次问纯个人昵称+一句话产品（目标市场可选），拿到即 ack 开工门并直出 8 项档案、再问目标客户网址（有→样板分析，无→平台客群推演）；连接前不问昵称产品、不催粘贴 token。
2. **主动索取并分层回落**：公司名/官网/联系邮箱/默认市场→`.local/operators/<operator_key>.md`；产品线/卖点/认证/产能/MOQ/交期/价格带→当前 product-profile。每次单独问一组、给填空模板、可跳过不逼问。邮件末尾签名区只有昵称；confirmed 且有字段级来源的产品事实可进正文卖点；潜在买家/联系人第三方资料不索要。
3. **真实能力**：系统不自动识别回复/不自动打标签；人/AI助手打"询盘"标签且实际生效后才停邮件。
4. **确认不豁免**：用户说"自由发挥"只能跳过展示，写操作确认与审批不能跳。
5. **断言分级**：实测✅/引用📚/推断⚠️/假设❓——不把假设说成事实。
6. **邮件正文英文、内部命名中文、标签=客户群体名（非产品名）**。
7. **适配预期管理**：S0 先按 specs/product-fit.md 判强/条件/弱适配并展示结论；客群成交/询盘周期以季~年计时（条件/弱适配），如实说明 12 步节奏按快周期品类设计、建议先不激活（轮数固定 12）、等有需求再开，或转人工低频培育。
