# S0-连接未通过 · 检查没通过/中途停下时怎么跟用户说

> **展示时机**：①连接检查（"开始前体检"）没有全部通过 ②**流程中途任何一步卡住/失败/需要停下**（见下方「其他步骤卡住」表）。
> 与 [S0-连接成功](S0-连接成功.md) 成对：那张讲"成功了显示什么"，这张讲"没成功怎么讲"。
> **为什么需要**：2026-09-11 用户实测——某次检查没通过，AI 给用户的是
> `onboard_check.py：通过` / `gate_check.sh：未通过` / "登录复核和工作空间落点复核均失败"，
> 满屏工具文件名和行话，小白只看到"失败"，不知道**是不是自己账号坏了**、**下一步该干嘛**。
> 而且那次其实是"AI 还没收到账号钥匙"，**不是账号有问题**——被转述成了"均失败"。

## 话术一：只是还没收到您复制的信息（最常见）

```
⛔ 我先停一下——**不是您的账号有问题**，是我还没收到您复制的那两行信息。

您只需要做一件事：回浏览器把刚才那条复制命令再执行一次，
把复制到的两行直接粘贴到聊天框**回复我**。

（这次只做了检查：没有搜索客户、没有保存、没有扣点。）
```

## 话术一·补：内容没复制全（粘少了/粘错了东西）

```
⚠️ 我收到的内容好像没复制全（缺了一段）。

您只需要做一件事：回浏览器把那条复制命令再执行一次，
把复制到的两行整段**回复我**。

（不用重新登录，也不用改格式。）
```

## 话术二：信息用不了了（过期/换设备登录过）

```
⚠️ 检查没通过：您给的登录信息用不了了（可能已过期；在别的设备登录过也会让它失效）。

您只需要做一件事：回浏览器重新执行一次复制命令，把新复制到的两行**回复我**。

（这次只做了检查：没有搜索客户、没有保存、没有扣点。）
```

## 话术三：连到了别的工作空间

```
⚠️ 检查没通过：您给的信息是有效的，但它连到的**不是您想用的那个工作空间**，
我怕客户存错地方。

您只需要做一件事：在来发信网页右上角切换到您要用的那个空间，
再重新执行一次复制命令，把两行**回复我**。

（这次只做了检查：没有搜索客户、没有保存、没有扣点。）
```

## 话术四：网络/平台临时问题（不是用户操作错）

```
⚠️ 这次没检查成功，是网络或平台临时抽风，**不是您操作错**。

您什么都不用做，等几分钟我再试一次；如果反复出现，**回复我**说一声就行。
```

## 话术四·补：有一项没能确认（平台没返回判断依据）

```
⚠️ 有一项没能确认（平台这次没返回判断依据），**不是您操作错**。

您什么都不用做，我稍后再核对一次，确认好之前我不会保存或发送任何东西。
```

## 话术四·补二：需要您先确认产品资料

```
ℹ️ 在正式开始前，我需要您先看一眼产品资料整理得对不对（我会把要点列给您，您回复确认或修改就行）。
```

## 话术五：其他卡点（说不清原因的停下）

```
ℹ️ 我这边的准备工作还差一点（我来处理，**您不用管**），处理完我再请您继续。

目前没有动您任何数据：没搜索、没保存、没发送。**请您**先等我一下。
```

## 其他步骤卡住时怎么说（通用三句话）

> 不管卡在哪一步，都按这三句说：**①哪一步没成 ②跟您有没有关系 ③您现在要做的一件事**。
> 下面每行给的是「①」的现成人话；②③按实际填，多数情况是"跟您没关系，我来处理"。

| 卡在哪 | 对用户说（① 现成人话） | ③ 通常的下一步 |
|---|---|---|
| 找买家方向推演没出来 | 我没能把"该找哪些买家"推演清楚（我来换角度重试） | 我重试；若两次都失败，请您用一句话补充"您卖的是什么、主要卖到哪" |
| 找不到合适的样板买家 | 我没找到足够像的样板买家来当起点 | 请您发一个您认识的同行/买家网址给我；没有的话我换关键词再找 |
| 抽查名单质量没过关 | 这批名单质量不够（不够像您的买家），我没敢往下存 | 我换关键词/换样板重找；您不用操作 |
| 名单不够/超出预期 | 找到的名单数量与预期不一样（我核实一下原因） | 我把实际数量重新报给您，您再决定存多少 |
| 点数/额度不够 | 您账户的可用额度不够完成这一步（不是出错） | 我把差多少报给您，您充值后再继续；已完成的进度不会丢 |
| 开发信没通过检查 | 有几封开发信没达到标准（写得太像/缺关键信息），我退回去改 | 我改好再给您看；您不用操作 |
| 批量写开发信中断了 | 批量写开发信时中断了（我来续；已写好的不会重复建） | 我继续跑；您不用操作 |
| 建跟进计划失败 | 跟进计划没建成功（我来重试） | 我重试；连续失败我会把原因说给您 |
| 客户加进跟进计划失败 | 把客户加进跟进计划时出问题了（我来核对） | 我核对数量后重报给您确认 |
| 激活失败 | 启动发送没成功（我不会在没有您明确同意时重试） | 我把原因说清楚，您决定是否再试 |
| 平台没响应/网络问题 | 平台刚才没响应，这是临时的（不是您操作错） | 您什么都不用做，我几分钟后重试 |
| 不确定是什么问题 | 我这边有个环节没走通（我来查） | 我查清后告诉您原因和下一步；**在此之前不会动您的数据** |

**通用兜底话术（上面都对不上时用）**：

```
ℹ️ 我这边有个环节没走通，我先停下来查一下（我来处理，**您不用管**）。

在此之前没有动您的数据：没搜索、没保存、没扣点、没发送。
我查清楚原因后马上回来告诉您，需要您做什么我会只说一件事。
```

## AI 执行要点与边界

- **★以工具输出为准（单一真源）**：`bash tools/gate_check.sh --credentials-stdin` 输出的最后一段「给用户看的这一段」是**权威版本**；本卡话术若与之有细微出入，**以工具输出为准**（避免双源漂移误导用户）
- **★先照工具给的现成话**：上面那段的用法——
  「给用户看的这一段」已经是白话，**直接照抄**（可微调称呼），不要自己重新组织、
  更不要把上面那半截「体检明细」转述给用户
- **★分清"没收到"和"不通过"**：
  - **还没收到账号钥匙** → 这是流程没走完，**必须明说"不是您的账号有问题"**（最常见误解）
  - 钥匙过期/换设备登录 → 让用户重新复制一次（**同一份反复贴没用**）
  - 钥匙有效但空间连错 → 让用户切换工作空间后重新复制
  - 网络/平台临时问题 → 明说"不是您操作错"，用户**什么都不用做**，AI 稍后重试
- **★必须给唯一下一步**：失败汇报最后一句**只能有一个动作**（"回浏览器再复制一次发我"），
  禁止罗列一堆可能性让用户自己选。禁止只说"已按规则停止"就结束——那等于把球踢回去还不说规则
- **★禁止抛工具名与行话**：不得出现 `.py`/`.sh` 文件名（如 `gate_check.sh`/`onboard_check.py`/
  `check_login.py`/`workspace_guard`）、`rc=`/退出码、`落点`/`凭据`/`校验未通过`这类内部词。
  工具原始输出（`[PASS]`/`[FAIL]`/`结果: 通过=…`）**只给自己看**
- **★"如实汇报"=说人话，不等于转述工具原文**：如实指的是不隐瞒"没通过"，但用户要听的是
  **哪一步没成、跟您有没有关系、您要做什么**，不是哪个脚本返回了什么码
- **★不隐瞒也不夸大**：没通过就说没通过，但**不要**说成"账号失败/登录失败"——多数情况
  是流程还没走完或平台临时问题，说错会让用户反复重登、作废掉本来有效的钥匙
- **恢复后要回成功卡**：用户重新发来信息、检查通过后，改按 [S0-连接成功](S0-连接成功.md) 展示账号状态
- **★通用兜底**：上表对不上的情况，用「通用兜底话术」——说"我来查"，**不要**猜个原因编给用户，
  也不要因为说不清就把工具报错原文抛出去。**说不清就说说不清，但一定要给一个"我来处理"的承诺**
- **★卡片本身的引导**：每个步骤开始时（不是失败时）也该先给用户「三句话」——
  现在在做什么、要不要您动手（+预计多久）、完成后会请您确认什么。参考 `S4-审计进行中.md`/`S8-模板构建中.md` 的写法
- **用户可见文案纪律**：本卡片代码块内即为用户可见文本，同样受 `tests/test_user_facing_copy.py` 扫描
