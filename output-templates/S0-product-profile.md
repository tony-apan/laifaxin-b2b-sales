# S0 产品知识档案确认（AI 提炼 → 用户确认 → 回落）
```
进度：第 1 步 / 共 6 步
现在：账号已连上、昵称和产品也收到了——产品资料我直接整理好了，请您核对
该回什么：没问题回「确认」；要改直接说改哪

【产品资料 · 待您确认】我根据 <您提供的产品资料 / 您跳过后允许使用的通用口径> 整理出下面这份资料。它存在您电脑上，不会上传到来发信平台；整理时内容会经过您现在用的 AI，按其隐私政策处理。后面找客户、写开发信都以它为准。

💡 **一句话总结**：8 项我按现有资料整理好了，**其中 3 项请您重点看一眼**；暂时没可靠来源的我会标「暂无」，不编。

| 字段 | 内容 | 来源 |
|------|------|------|
| ① 产品定位 | <一句话：卖给谁/解决什么> | <您说的 / 官网原文 / 我的推断⚠️ / 暂无> |
| ② 产品线 | <品类/子品类/SKU/成分配比> | <同上> |
| ③ 核心卖点 | <1. … 2. … 3. …（每条一句，≤5条）> | <同上> |
| ④ 目标买家类型+市场 | <国家/语言/渠道角色> | <同上> |
| ⑤ 规格/认证 | <型号/标准号/证书/参数——有来源才写> | <同上> |
| ⑥ 差异化 | <和竞品比强在哪> | <同上> |
| ⑦ 合规/禁忌 | <禁运区/受管制品类/环保声明——有依据才写> | <同上> |
| ⑧ 可引用数字 | <产能/MOQ/交期/价格带——用户给或官网可查才写，没有不编> | <同上> |

📌 表格里每项我都标了来源：<您说的 / 官网原文 / 我的推断⚠️ / 暂无>。认证、产能、起订量、交期、价格这些，没有可靠来源我不会写进资料。
📌 以后您补充资料，我会更新这份资料；之前基于旧版做的开发信会提示您重新确认。

请您重点核对这三项：**③核心卖点**、**⑤规格认证**、**⑧可引用数字**（对上表编号）。

**要改的地方直接说；没问题回「确认」两个字（这一步不回数字）。**

👉 顺便说一件事：您手上有没有**目标客户（询盘客户/老买家）的官网**？注意是**客户的网址，不是您自己的官网**。有就发我，我定位并分析它当样板，起点更准、少走弯路（只收公开网址，不用发联系人邮箱/电话）；**已给过就不再问**。没有或先跳过也行——我直接让平台列出几类可能买您货的买家，给您候选建议。

您确认之后的流程：①（账号在开工第一步已连好，无需再连）若您给了目标客户网址，我先定位并分析这个样板客户；
②平台列出几类可能买您货的买家并附建议，请您挑——每一步我都会先说清要做什么、大约多久、要不要您动手。

该回什么：没问题回「确认」两个字（这一步不回数字）；要改直接说改哪。
```

## AI 执行要点与边界
- ①S0a 公司资料按需：首次安装不主动弹（避免多占一轮回复）；用户主动提供公司资料/官网，或换产品/换机复用时才邀请，可跳过 → ②用户给自己的网址时先走独立 `website-profile-sop.md`，生成六区候选并按 `S0a-website-profile.md` 展示，批准后才导入；用户给文字/文件则按用户来源提炼；没资料/跳过也可 init --declined → ③按模板展示正式档案 → ④确认后用 `product_profile.py confirm` 回落
- 公司名/官网/联系邮箱属于公司级资料，回落 `.local/operators/<operator_key>.md`（见 operator-profile-sop）；认证/产能/MOQ/交期/价格带属于当前产品档案
- 邮件末尾签名区只有昵称；confirmed 且有来源的产品事实可用于正文卖点；客户/联系人第三方资料禁止写入本档案
- 来源值域必须是：`用户` / `URL:https://...` / `推断` / `none`。网站硬事实必须有具体 URL 和原文；数字与认证无来源一律不导入正式档案
- 档案与用户一句话产品/目标市场冲突 → 以用户口径为准并标注差异
- **用户发产品照片/链接代替文字时**：先复述「我看这是 <产品>，对吗？」请用户确认；确认后按该来源提炼，不要求用户改发文字；照片里看不清的认证/参数标「暂无」，不猜。
- 部分字段填入后，直接用 `product_profile.py confirm` 做写入前结构/来源校验并重算 `sources_status/sources_present`，再运行 `validate --require-confirmed` 终检；不要在 partial draft 时先单独 validate，把预期的来源状态未重算误报成档案失败
- 回落成功后，后续 S2 客群/S4 客户线/S7 卖点/S9 钩子全部从该档案取知识
- **用户可见文案纪律**：代码块内（用户看到的部分）不出现 `runs/`/`status=`/`sha256`/`profile_version`/`content_sha256`/`draft`/`confirmed`/`declined` 等内部术语——这些只在"AI 执行要点"里给 AI 看
- **目标客户网址分流是必给项**：档案展示后必须用代码块末尾"👉 顺便说一件事"问一次「有没有目标客户（客户、非自己官网）网址」（不追问、不阻断）；有→定位并分析样板客户再进客群；没有/跳过→直接平台客群推演并给候选建议；**已给过网址不再重问**；用户未回答不得当作「没有网址」的确认
- **连接已在档案之前完成**（安装自检通过后第一业务动作，见 `T-token-guide.md`）；档案确认后不得再让用户连平台，也不得跳过客群建议直接保存
