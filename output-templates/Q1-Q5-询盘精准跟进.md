# Q1-Q5 询盘接管与精准跟进（给用户展示的话术模板）

> 适用：客户回复开发信、索要价格/目录/样品，或只说一句 “Interested / Send details”。询盘后不要继续套用群发话术。

```markdown
【收到新询盘，已转人工精准跟进】

我先做了两件事：
1. 人或 AI 助手已给联系人打「询盘」标签；只有标签实际打上后，邮件序列才会停止后续轮次；
2. 已登记他是从第 <轮次> 轮、主题《<邮件主题>》回复的。

## 客户说了什么
> <客户回复原文>

人话总结：<对方明确问了什么；哪些信息还没说>

## 背调结果
| 核实项 | 结果 |
|---|---|
| 公司 / 官网 | <公司名> · <域名> |
| 国家 / 市场 | <国家> · <主要市场> |
| 主营产品 | <官网看到的主营> |
| 客户类型 | <品牌商/批发商/零售商/集成商/终端> |
| 采购逻辑 | <为什么可能购买我方产品> |
| 联系人角色 | <Buyer/Owner/非决策人/待确认> |
| 公开商务渠道 | <WhatsApp/LinkedIn/电话；没有就写“未找到，不臆造”> |
| 与我方匹配度 | <高/中/低> · <一句理由> |

## 意向分级
**<A/B/C/D> 级：<一句判定>**

- A：规格/数量/交期或项目明确，快速报价、样品、电话/会议；
- B：公司匹配但需求模糊，给精选资料并追问用途/数量/市场/时间；
- C：暂时无预算或远期，低频长期培育；
- D：拒绝、退订或无效，打「不发」标签并停止所有渠道。

## 建议回复
> <根据官网与询盘内容写的定制回复；先回答对方问题，再问 1-3 个必要问题>

## 下一步
- 负责人：<姓名>
- 截止时间：<时间>
- 下一动作：<报价/样品/目录/电话/WhatsApp/LinkedIn/等待>
- 下次跟进：<日期与理由>

说明：询盘只是信号，不等于订单。有些客户只是问价或比价；背调和长期跟进才是精准开发阶段。
```

## 渠道边界
- 邮件：正式报价、规格、图纸、样品与合同，默认主渠道。
- WhatsApp：仅在客户已明确同意通过 WhatsApp 接收商务消息后使用；公开号码本身不等于许可，并遵守 WhatsApp Business 模板、窗口和退订规则。
- LinkedIn/商务社媒：核实角色、关注公司动态、建立长期关系；不拼装私人账号。
- 电话：仅用于 A 级急单、重大确认或已预约沟通；逐市场核验适用规则、拒呼登记和内部不联系记录；说明来电主体与目的、显示可回拨号码，并在对方要求时提供有效联系方式。
- 客户明确拒绝或退订：立即打「不发」标签停止邮件序列，并由业务员在联系人档案登记渠道级拒绝记录，人工停止 WhatsApp、社媒和电话。
