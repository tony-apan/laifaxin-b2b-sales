# S10 加联系人确认
```
【加入跟进计划确认】保存的客户已全部就绪：

| 核对项 | 值 |
|---|---|
| 保存任务 | finished ✅ |
| 待加入联系人 | <N> 人 |
| 目标序列 | <序列名>（12步，未激活）|
| 对账 | 任务数=标签数=待加数 ✅ |

确认后他们进入 12 步跟进计划（计划本身还没激活，不会发信）。
回复"确认加入"。
```

## AI 执行要点与边界
- 三重前置缺一不可：保存任务 finished + 联系人标签>0 + 序列 inactive
- contact-add 必须带 views:[]（传 ["all"] 会把全库加进去！）
- 对账：任务 contactSaveCount = 标签人数 = 实际 add 数，三方一致才放行
- 加完不入序列即止，激活是独立的 S12 用户指令
