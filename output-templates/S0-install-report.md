# S0 安装完成汇报（小白话术 · 安装后第一句话）

> **展示时机**：安装/学习阶段结束。**新用户第一业务动作=连接平台**（连接成功前不问昵称/产品、不出菜单、不要数字）。
> **分支铁律（2026-10-27 用户裁决改序）**：
> ① 无任何历史项目 → 汇报完**立即先连平台**：优先复用已验证会话，否则按 `T-token-guide.md` 开专用浏览器自动连接（人工复制仅环境故障兜底）；**连接成功后一次问「昵称 + 产品」**（`S0-opening-questions.md` C1），拿到立刻登记开工门、给 6 步全景（`specs/beginner-flow.md` 第 1 屏）并直出 8 项产品档案。
> ② 检测到旧项目 → 汇报旧项目与人话进度，展示 `S0-task-menu.md`「有旧项目时」的 4 项菜单，等用户回编号。
> 旧版「先问两样再连平台」与「汇报完一律给 4 项菜单」均已废弃（2026-10-27 改序；菜单废弃源于新手实测）。

## 话术（新用户 · 无旧项目）

```text
✅ 我这边已经装好了、检查通过，您不用装任何东西。

我能帮您做：找海外买家、写开发信、排跟进计划。第一次发信前我会先问您，您不说「确认激活」，一封都不会发；之后按确认好的计划自动发，不会每封都问。存客户前我会先说要扣多少平台额度，您同意再存。

有人回复不会自动停——您看到回复告诉我，我马上给这个人打上「询盘」标记；标记生效后就不再自动给他发（平台只给回复总数，看不到具体是谁）。

第一步先连您的来发信账号（约 3–5 分钟）。这一步只做连接检查：不搜索、不保存、不发信、不扣点。我会先沿用您电脑上已验证过的登录；没有就打开一个专用浏览器窗口，您在里面登录来发信就行——不用把密码发给我；实在连不上，我再给您一条可复制的兜底办法。连不上多半不是您操作的问题，我来处理。

👉 现在轮到您：看到专用浏览器窗口就在里面登录来发信（已有账号直接登录；还没有就去 laifa.xin 免费注册一个，免费），登录好回我一声「登录好了」。
```

（以上连接话术与 `T-token-guide.md` 自动连接分支同源，不得另写一套；连接成功后的两问见 `S0-opening-questions.md` C1——一次问齐，若已知昵称只问产品。）

## 话术（老用户 · 有旧项目）

```text
✅ 环境检查过了，可以直接用。

我发现您之前跑过项目，进度我记着：

  📂 <项目名（大白话，如「皮筏艇找客户」）>——上次做到「<进度白话>」

接着上次做，回复「1」就行，不会从头再来；已保存过的客户我会跳过、不重复保存。实际扣点以平台账单为准。
```

（紧接着展示 `S0-task-menu.md`「有旧项目时」的四项菜单）

## ★状态码白话对照（AI 内部用，禁止把左列原话给用户）

| 内部状态 | 对用户怎么说 |
|---|---|
| S0 / S0a | 刚开始了解你的产品 |
| S1 | 准备选从哪里开始找客户 |
| S2 | 正在推演「该找哪些买家」 |
| S3 | 在挑一个合适的起点（买家样板） |
| S4 | 在抽查名单质量 |
| S5 / S6 | 正在保存客户名单 |
| S7 / S8 | 正在写开发信 |
| S9 | 正在排跟进计划 |
| S10 | 正在把客户加进跟进计划 |
| S11 | 全部准备好了，等你决定要不要开始发 |
| S12 | 已激活，正在发送中 |
| ERROR_BLOCKED | 中途卡住了，需要你看一下 |

**用法**：`onboard_check.py` 输出的 `流程状态=S10` 这类信息，只给自己看；
对用户必须翻译成右列，例如「上次做到**正在把客户加进跟进计划**，差最后一步」。

## AI 执行要点与边界

- **★先说「装好了」（以机器判据为准）**：安装门 = `onboard_check` 退出码 0；只看到「✅ 安装/学习自检完成」不算（缺依赖时也会打印）。`preflight` 是**维护者发布门**（文档链接+全量测试+规则检查），安装阶段不跑、不对用户提，失败也不算安装失败。通过才说「装好了/可以用」，不要先讲技术细节；不通过就说「还差一个组件，我来处理，您不用管」，**不得说已装好**
- **★连接成功后一次问两样、先登记再发第 1 屏**：连接成功后按 C1 一次问「昵称 + 产品」，拿到先跑 `startup_gate.py ack --nickname <昵称> --product <产品>`，登记成功再发 6 步全景并直出 8 项档案（未知写暂无，不问「要不要整理」）；用户分两条发也接受，合并成一条登记
- **★新用户结尾是连接引导，不是菜单也不是两问**：连接成功前**禁止**问昵称/产品、**禁止**展示 4 项菜单、**禁止**要求回数字；连接失败按 `S0-connect-failed.md` 三行话术白话有限重试，不让用户自己排查
- **★老用户才给菜单**：检测到 `runs/*/*/operation-record.md` 才展示 `S0-task-menu.md`「有旧项目时」4 项
- **★只讲用户关心的四件事**：①装好没有 ②能帮做什么（3 条以内，人话）③哪些必须你确认 ④有无旧项目
- **★禁止抛术语**：不得出现 `S10`/`contact_add.py`/`status=declined`/`.local/`/`runs/`/`bootstrap.sh` 等；`onboard_check.py` 原始输出**只给自己看**
- **★必须强调「等你点头」**：明确「你不说确认激活，一封都不会发」
- **★环境异常时如实说白话**：自检不过时说「还差一个组件，我来处理，您不用管」，不要说已装好，也不要把报错原文给用户
- **★内部排查不进首屏**：文件路径/行号、测试数量、失败条数、文档口径冲突、脚本名，只留在 AI 自己的工作记录或给作者的反馈里（可先对话内备注，开工后补进项目记录），不得出现在给用户的任何一句话里；口径冲突以 `AGENTS.md` 安装门 + 本模板为准，AI 自己处理，**不得让用户裁决内部文档**。
- **用户可见文案纪律**：不出现 `status`/`.py`/`.local/`/`runs/`/`flow_orchestrator`/`S0`-`S12` 等内部术语
