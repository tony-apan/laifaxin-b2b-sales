## AI 执行要点与边界
- **展示时机**：安装自检通过后立即连接（第一业务动作），连接成功后才问昵称+产品并直出档案；不在档案确认之后才展示（2026-10-27 用户裁决改序；`RULES.md` S0「禁止开局催 token」指安装动作进行中不得索取，安装汇报后的连接引导不受此限）
- **用户说「不想连 / 先别连」时**：先一句话说明为什么必须连（找客户、查名单、存客户的数据都在您账号里，不连就什么都做不了），再给两个选择：1＝现在连（默认，回到本卡）；2＝我先看看完整流程/先准备产品资料，连接留到您方便时。**不得静默跳过连接去推演客群，也不得反复催**；用户选 2 就停下等，不扣点、不动数据。
- **★用户没有账号时先引导注册（2026-09-09 对抗审查补）**：若用户说"我没有来发信账号"，先让用户去 https://laifa.xin 点页面上的「免费注册」（注册免费）并登录，再回到本卡继续；**AI 不代办注册、不代填手机号/邮箱、不承诺具体权益数额**。权益/套餐/赠点一律让用户以官网客服实时答复为准
- **★首选自动连接（2026-10-27 用户裁决）**：先跑 `tools/browser_login.py`（专用 Chromium 窗口，用户在窗口里登录，工具取参），成功就跳过所有粘贴步骤；只有它返回环境/超时类失败，才降级到本卡的兜底 4 步。禁止一上来就让用户贴控制台代码
- **检查顺序**（主 AI 内部执行，结果用白话汇报，不抛错误码）：
  1. `check_login.py --credentials-stdin`（经宿主程序化 stdin，凭据不进 argv/文件/日志）
  2. `workspace_guard.py --credentials-stdin --require-verified`（落点校验；命中误路由必须停止）
  3. 通过后按 `S0-connect-success.md` 展示账号状态卡
- 用户在浏览器复制后，只需把 `accesstoken=` + `orgId=` 两行整段直接粘贴到当前聊天框；**禁止要求用户设置环境变量、创建 `.env`、执行工具命令、拆分或改写参数**；**禁止声称"只读 token / 只读授权"**——平台没有这种权限级别（见 `RULES.md` 审查代理权限）
- 主 AI 收到后不回显完整 token、不写文件/日志/持久环境变量；通过宿主提供的**程序化 stdin**（如 subprocess `input=`/`communicate()`）原样交给 `check_login.py --credentials-stdin`。禁止用 heredoc、`printf |` 或把凭据拼进 Bash 工具调用文本，避免进入命令历史/工具日志
- **失败分流（白话）**：
  - 没登录/凭据失效 → 让用户回浏览器重新执行同一条一键复制命令后，再把新的两行整段发到聊天框；同一份反复重试无意义
  - 网络/接口空 → 说明"这是网络或平台临时问题，不是您操作错"，稍后重试
  - 落点不匹配（声明企业却连到个人空间）→ 停止，让用户切到目标工作空间重新一键双取
- accesstoken 或 orgId 任一缺失/null → 停止连接，不得回退 token 中段或默认个人空间
- **★用户只发了一段（2026-09-18 强化）**：用户可能被**别的工具/教程**教了"只复制 accesstoken"的单取命令
  （或粘贴来一段裸 token）。处置：①**不继续**（缺 orgId 无法确认工作空间）②**不要**让用户再跑一条
  "只取 orgId"的第二条命令（多余动作且容易再错）③把本卡的**完整一键双取命令**再发一次，让用户重新复制
  （一次拿两行）④白话解释："您发的只有一半——用我给的完整命令重新复制一次就行"。工具会对
  "只有账号钥匙/只有工作空间编号"给出对应的白话提示，AI 照抄即可
- **★已给的值不重问（2026-09-23 真机事故：AI 对用户已发的 orgId 不依不饶反复索要）**：token/orgId 用户在
  **任何一条消息**里发过即视为已提供——AI 自行取出拼装喂 `--credentials-stdin`，**禁止再向用户索要已给过的值**。
  手拼粘贴的格式差异（键一行值一行、全角冒号「：」、大小写混写、首尾空格）工具已自动兼容，不得以"格式不对"
  让用户重发，更不得教用户改格式。拼装只能用用户原话里已有的字符，禁止把 token 中段补当 orgId（缺才走上面的只发一段处置）
- **★orgId 对错由工具裁决，禁止 AI 凭 token 中段猜（2026-09-23）**：个人账号 orgId==用户ID（token 中段）是
  **合法正确**的值（`workspace_guard`：isOrg=false 且 org==uid→通过）；企业账号才另配独立数字ID。跑
  `workspace_guard` 前禁止断言"这是 UID 不是 orgId"——先跑，按结果走：通过→继续；exit 1=落点不匹配
  （用户给的 org 未被平台采纳）按失败分流处理；exit 5=无法判定话术
- **★凭据排查不当调试员（2026-09-23）**：排查由 AI 用工具完成；禁止让用户查浏览器右键菜单有没有「检查」、
  发屏幕截图、读控制台报错来"帮 AI 排查"。唯一重取场景=工具明报凭据失效→把本卡的完整一键双取命令再发一次
- **orgId=工作空间ID**（localStorage `orgId` 键）：个人账号=用户ID本身；**企业账号是独立数字ID**——所有平台调用用它，且必须放**请求头 `uid`**（query `?uid=` 无效，平台不读）
- token 中段=用户ID（切换 org 不变）；不能用 token 中段当企业 orgId
- 连接成功后按 S0-connect-success.md 展示账号状态（含 org 信息）
- token 等同账号密码：只直接粘贴到当前受信任、正在本机操作的主 AI 聊天框，不发群聊/子代理/工单/公开页面。仓库工具不主动回显或落盘原始凭据，也不写 `.env`/日志；仅在失效时于本机 `.local/` 保存不可还原的短哈希和重试次数。聊天服务是否保存对话取决于所用 AI 的隐私与数据保留政策
- **★失败情形对照（AI 自己知道即可，不要预先甩给用户）**：拿到 null=还没登录→让用户先登录；切换过账号/企业→orgId 会变，让用户重新复制；**token 单点有效**（别处登录即作废）→同一份反复贴没用，让用户重取；域名是 `web.laifaxin.com` 或 `web.worldtradetool.com` 等都正常不用管。这些只在**实际遇到**时按失败卡的白话讲，不在引导阶段预读给用户（2026-09-17 对抗审查：7 条提示墙会放大畏难心理）
- **用户可见文案纪律**：不出现 `status`/`sha256`/`hash`/`runs/`/`.py`/`approval`/`S0a` 等内部术语；不出现 `SEND_READY` 之类英文状态码；不出现"单测""文件已更改"这类开发信息

## 昵称边界
- 新获客项目通常已在 S0 获取纯个人昵称，连接账号后不要重复问
- 如果当前任务只是适配判断、网站提炼或流程了解，本来不需要昵称/token；不得为了套流程额外索取
- 真正生成邮件时，昵称只放个人称呼（Tony / Iris 等）；公司名、产品名、职位不进入昵称或签名
