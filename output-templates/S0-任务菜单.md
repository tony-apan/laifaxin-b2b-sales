# S0 任务菜单展示（安装完成后 · 唯一要展示的菜单）

> **展示时机**：安装/学习阶段结束后。**不得**索取产品、市场、官网、昵称、token。
> **格式铁律（2026-09-10 用户拍板）**：菜单**必须逐行 + emoji 突出 + 标注 ⭐推荐**。
> 旧版把 1-6 压成 `①②③④⑤⑥` 连成一行 → 用户看不出该选哪个，**违例**。

## 有旧项目时（推荐「继续以前的项目」）

```
✅ 安装完成，环境自检通过。你现在想做什么？

  1. 🚀 开始一个新的获客项目
  2. 🎯 判断产品是否适合批量冷邮件
  3. 🌐 从自己的官网、产品页或目录提炼资料
  4. 📂 继续以前没做完的项目（发现 <N> 个：<项目名·当前节点>）  ⭐推荐
  5. 🔄 更新系统或换电脑继续
  6. 📖 先了解完整流程

回复编号即可（如「4」）；不确定回「6」我先讲一遍流程。
```

  1. 🚀 开始一个新的获客项目  ⭐推荐

## AI 执行要点与边界

- **★逐行展示**：6 项必须**各自独立一行**，禁止压成一行或用 `①②③` 连写（用户截图反馈"1234 不明显"）
- **★emoji 突出**：每项前一个 emoji（🚀🎯🌐📂🔄📖），让用户一眼扫到；emoji 可与项内容不严格对应，但必须稳定一致
- **★必须标注推荐**：用 `⭐推荐` 明确标出该选哪个——有旧项目推荐④，无旧项目推荐①。**不标推荐 = 违例**（用户不知道该选什么）
- **★推荐是建议不是代选**：标了推荐仍等用户回复编号，不得替用户选、不得默认进入 S0
- **结尾给最短回复指引**：一句"回复编号即可（如「1」）"，降低回复门槛
- **★此阶段禁止**：问产品/市场/官网/昵称/token；默认建新项目；展示 6 项以外的内容
- **用户选具体任务后**，才按 `../SKILL.md` 对应路由渐进询问；只有选「开始新的获客项目」才问纯个人昵称 + 一句话产品
- **emoji 使用边界（易混）**：**本菜单/聊天话术鼓励用 emoji 突出**；但**邮件正文**禁 emoji 堆砌（`specs/sequence-config.md` 视觉扫读铁律：≤1 个且仅当品类天然适配）——两处规则不同，不要混用
