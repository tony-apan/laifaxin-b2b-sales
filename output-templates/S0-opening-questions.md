# S0 开场提问（两个分支：全新安装 / 有历史项目）

> **先判分支，再开口**：读取本地有没有历史项目，只影响"怎么开场"，不影响必填项。
> 判定口径以 `tools/opening_gate.py` 为准（无项目或读取失败→全新分支；有项目→先给选择）。

## C1 全新安装（没有任何历史项目）——只在平台连接成功之后使用

> **时机（2026-10-27 用户裁决改序）**：新用户先连平台（见 `S0-install-report.md` 与 `T-token-guide.md`）；**连接成功前不得问昵称和产品**，连接失败走 `S0-connect-failed.md` 白话重试，不进入本节。本节话术以「账号已连好」开头，避免重复装机汇报。已有项目（C2）复用已有会话与档案，不重复问昵称/产品、不重做保存。

### C1a 未知昵称（一次只问两样）
```text
✅ 账号已经连好了（刚才只做了连接检查：没搜索、没保存、没扣点）。

先确认两件事，您一条消息回两样就行：
1. 怎么称呼您？（个人昵称，Tony / Iris 这种）
2. 您家主要卖什么产品？（一句话，比如「不锈钢保温杯」）

（卖给谁不用现在告诉我——我先用平台列出几类买家，列出来您挑。）
```

### C1b 已知昵称（只问缺的产品）
```text
👋 **<昵称>**，咱们开始吧。

先只问您一件事：**您家主要卖什么产品？** 一句话就行（中文英文都可以，比如"不锈钢保温杯"）。

（**不用告诉我卖给谁**——这个由平台来帮咱们找，我只负责把产品说清楚。）
```

### C1c 用户只答了一半 / 回了数字 / 只发了产品照片（不要硬套 C1a，也不要重问两样）

> 判据：第一条消息里昵称、产品是否**都**有；缺哪个只补问哪个，最多一句话。用户回「1」「开始」「你好」这类，不算昵称，**不得把数字当昵称登记**。

```text
收到。还差一样就能开始：**您想让我怎么称呼您？**（回个昵称就行，Tony / 阿杰 这种）

产品我按「<已有产品；没有就写"您刚才没提，也告诉我一句">」记。
```
- 只有产品、没昵称 → 用上面这段，只补昵称；
- 只有昵称、没产品 → 用 C1b，只补产品；
- 只回数字/表情/「你好」→ 先用一句话说「我在，先告诉我两样：怎么称呼您 + 您家卖什么」，**不要把它当昵称**；
- 只发产品照片/链接 → 先复述「我看这是 <产品>，对吗？」；用户确认后再登记，不要求重发文字。

## C2 有历史项目（先给选择，不直接展示历史）

> **复用任务菜单，不另造菜单**：直接用 `S0-task-menu.md`「有旧项目时」的四项；只把第 1 项换成真实产品别名与阶段。
> 阶段值只能取自 `tools/onboard_check.py` 的 `PLAIN_HINT` 或 `S0-install-report.md` 的白话对照表。

```text
✅ 安装完成，环境自检通过。您现在想做什么？

  1. 📂 继续「<产品别名>」（现在：<人话阶段>）  ⭐推荐
  2. 🚀 开始新的获客项目
  3. 🌐 用我的官网、产品页或目录提炼资料
  4. 📖 先了解完整流程

回复编号即可（如「1」）。想先看看之前做到哪，直接说「看看之前做到哪」。
```

## C2b 用户选了「继续」或说「看看之前做到哪」之后（最少必要信息）
```text
我这边记着这几个（只说重点）：

- **<产品别名>**：<人话阶段，如"全部准备好了，等您决定要不要开始发">
- **<产品别名>**：<人话阶段>

还有 <N> 个更早的项目，要看吗？

要接着哪个，回编号告诉我一声。
```

## AI 执行要点与边界

- **分支判定**：无任何历史项目或本地读取失败 → 用 C1（只问昵称+产品），**禁止**说"我记得您…"；有历史项目 → 先发 C2，**不得**直接贴历史清单。
- **★历史分支复用任务菜单（K8）**：C2 就是 `S0-task-menu.md`「有旧项目时」的四项（逐行 emoji、⭐推荐），**不另造一套开场菜单**；用户选「1 继续」或说"看看之前做到哪"才发 C2b。
- **★阶段文案不自造**：只能取自 `onboard_check.py` 的 `PLAIN_HINT` 或 `S0-install-report.md` 的白话对照表（如 S11→"全部准备好了，等您决定要不要开始发"）；只列当前运营方的项目，不显示路径/凭据/余额。
- **最少必要信息**：每个项目只给「产品别名 + 人话阶段」（如"名单存了、还没发信"）；一次最多 3 个，超出必须说"还有 N 个更早的项目，要看吗"。
- **展示值转义 markdown**：产品别名里的 `* _ [ ] # | >` 等一律转义（用 `opening_gate.escape_markdown`），防止排版被撑破。
- **禁止展示**：token/凭据、内部状态与枚举（S0-S12、status、next_state）、本地路径、跑批数量等开发信息；阶段一律说人话。
- **允许加粗、emoji 适量**：用户话术渠道是聊天框，不是微信/终端；一条消息别堆太多 emoji。
- **昵称必须过 `tools/profile_utils.py` 的 `validate_nickname`**；不合规请用户改，AI 不得代填、不得截断，也不在这里复制规则清单。
- 开场喊一次昵称即可；C1 一次只问两样，不追加市场/网址/token。
- **★C1 只在连接成功后触发**：连接成功前问昵称/产品、或连接失败仍追问，均违规；连接成功后拿到昵称+产品立即 `startup_gate.py ack`，再给第 1 屏并直出 8 项档案。
