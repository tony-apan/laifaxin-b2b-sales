# 🎯 临界点判定方法论（找 70% 保存边界）

> **目标**：找到"**从前往后最后一张 ≥70% 产品匹配率**"的页（临界页），保存它之前的全部。
> 核心：**不信任单页 + 不信任词匹配 + 临界方向一定往前找**。

## 一、判断标准（★v2 2026-08-31：三条客户线 = AI 反思，不是关键词）
- **产品匹配率** = 一页 10 条里，**"这个外贸 B 端客户会不会买我的成品/产能（OEM）/扩品供给"**的比例
- **★判断方式 = AI 语义反思**（不是关键词匹配）：对每条描述反思"**属于哪条客户线**"——判定单位是客户线，不是"是不是同行"
- ⚠️ **不是** "现在卖不卖这个产品"，而是"**作为外贸B端，有没有采购可能**"

### 客户线判定表（★v2 2026-08-31 用户拍板：国外同行很多是 OEM 客户）
| 客户线 | 谁 | 采购什么 | 判定 |
|--------|-----|---------|------|
| **直采线** | 渠道商/批发分销/零售/outfitter/运营商/涉水度假营地/船艇经销 | 成品（自用/转售） | ✅ |
| **OEM 线** | **国外品牌方/制造商（含做同产品的同行）** | 制造能力（贴牌代工） | ✅ 潜客（中国大陆及港澳台同行由保存时 4 区排除（CN/TW/HK/MO）兜底挡掉） |
| **拓品线** | 邻近品类商家（单一品类店**或**陆地主导综合店），判定原理=**零售同店性**：现有品类与目标产品在零售端常同店陈列销售（露营/综合户外店普遍设水上器材区、渔具店普遍卖充气艇、船电/码头店配套卖艇）——徒步鞋杖/攀岩器材等极少与筏艇同店的专项不属此线 | 目录扩新品类 | ✅ 潜客（宜配降低门槛型话术：低 MOQ/快速打样） |
| **非客户** | 纯媒体/内容/目录/评测、政府/事业单位、地产、家居/水族/泳装漂移、无涉水场景纯陆上（狩猎/ATV/摩托/马术/滑雪/山地车/徒步/攀岩/战术/生存） | 不采购 | ❌ |

### ★计数规则（v2 防混线池，P1-1）
- **匹配率以目标 segment 的客户线为分子**：如 S05（经销商档）审计——只有直采线渠道商计入该池匹配率与保存范围
- **其余 ✅ 线（OEM/拓品）单列计数为线索，不进本池匹配率、不进本池保存范围**（防制造商被打进"经销商"标签池收错话术，违铁律7）
- **落点（数据源→结构化）**：S4 审计每页判定表按客户线计数 → 写入 S5 确认材料与 seeds 表结果列（如「直采70%/OEM20%/拓品10%」）→ 模板生成按此占比加权痛点组合；OEM/拓品线索汇入 `runs/<运营方>/<产品>/leads-oem.md`（或 leads-拓品.md）
- **线索池启动**：任一线索积累到值得做档（如 OEM 线 100+ 家），开新 segment 走完整 S3→S4→S5（用该线公司做种子锚）

### 边界裁决（v2）
1. 制造商兼分销/自有品牌：**OEM 线潜客**（大小品牌都有代工需求；超级大牌确无 OEM 需求=边界，看规模/代工痕迹）
2. 综合店含涉水：涉水是明确品类/枚举=直采✅；陆地主导+渔具/露营附属且**具零售同店性**=拓品线（非❌；无同店性的纯徒步/攀岩专项仍❌）
3. 渔具店：明确卖充气船/筏=直采✅；纯竿线=拓品线
4. **角色字段不可信**：必看 summary_zh 语义，不能只信 operational_role
5. **敏感性检查**：临界页附近每个边界判定问"翻转它，临界变吗"——变则双算并披露
6. 输出统一：每页判定表（公司/角色/客户线/一句话理由）+ 边界案例单列

## 二、审计粒度（三阶段，从粗到细）
### 阶段1：50 页一跳全局（初筛趋势）
```
页: 1,50,100,150,...1000（20个点）
工具: audit_company.py --pages ... --mode moderate
目的: 看整体趋势, 定位"高→低"的下降带
⚠️ 工具是词匹配, 结果只能当趋势参考, **必须人工核对**
```

### 阶段2：三页滑动平均（★平滑单页波动）
**为什么**：向量搜索尾部单页波动大（472页40%、475页70%），单页不可信。
**方法**：每页匹配率，用**连续3页平均**判定：
```
第N页的三页平均 = (第N-1页 + 第N页 + 第N+1页) / 3
```
**判定**：三页平均 >= 70% = 达标；< 70% = 进入混浊区。

### 阶段3：临界附近逐页精确（1页精调）
- 在"达标区(低页)"与"跌破区(高页)"之间**往前逐页读**（100页→10页→1页）
- 找到**最后一张 >=70% 的页** = 临界页

## 三、临界方向（★铁律）
- **一旦某页/三页平均跌破 70%，就【往前找】，不看后面**
- 后面更差（杂质更多），没意义
- 往前找 = 在"最后达标页"和"首个跌破页"之间**逐页精确到1页**

## 四、人工读（★铁律，工具不可信；v2：判定单位=客户线，非二元）
- 工具词匹配会误判（bike 命中了 motorbike；水上运动潜水/水翼/风筝冲浪没被识别）
- **判定以人工读描述为准**：逐条第1条问"有没有可能买我产品"
- 工具只做"趋势初筛"，**临界页必须人工核读**

## 五、输出（v2：判定表须含客户线列——公司/角色/客户线/理由；他线计数见 §一计数规则）
```
种子: xxx
全局50页跳: 1-500页好(80-100%), 500后波动
三页平均: 临界在 470-475 之间
逐页精确: 470=80%✅ 471=80%✅ 472=40%❌
★ 临界页 = 471页（472页首跌, 三页平均57%<70%）
保存范围 = 前471页（4710家）
```

## 六、复盘总结（皮筏艇 nookie 案例）
```
种子 nookie.co.uk（白水装备制造商）:
  人工读: 400页80% / 450页80% / 460页80%
  470页80% / 471页80% ✅(最后达标)
  472页40% ❌(首跌) / 473页50% / 475页70%(回升)
★ 人工临界 = 471页, 保存前471页(4710家)
⚠️ 工具词匹配严重误判(把船只/海洋/风筝冲浪漏算, 400页说50%实际80%) —— 必须人工读
结论: 水上运动类种子尾段(~470页后)混入服装/摩托/除菌等——人工判471页
```

## 七、工具 vs 人工 vs AI反思（重要；★v2 注记：本节「能买=匹配」为 v1 二元口径示例，v2 判定单位=客户线，以 §一为准）
- **audit_company.py / find_critical.py**（关键词匹配）= 只做趋势初筛，**不可靠**（会把船只/海洋/风筝冲浪漏算，400页说50%实际80%）
- **★正确方式 = AI 语义反思**：对每条描述，**AI 反思"这是外贸B端，会不会买这个品？能买=匹配"**
  - 独立 AI（subagent）逐条推理：水上/船艇/潜水/冲浪/桨板/皮划艇/渔船装备零售与经营服务商 = 匹配
  - 服装/泳装/内容评测/APP/军事/能源/球类/疗法设备/中国区 = 不匹配
- **AI反思 + 人工读 两两印证**（一致才可信）：皮筏艇470=8/10、471=8/10、472=4/10

### 皮筏艇 nookie AI反思确定临界
| 页 | AI反思匹配 | 三页平均 |
|----|----------|---------|
| 470 | 8/10(80%) | — |
| 471 | 8/10(80%) | 80% |
| **472** | **4/10(40%)** | **67%<70%❌** |
| 473 | 7/10 | 70% |

**★ 合理临界 = 第 471 页**（471页80%最后达标；472页首跌40%，470/471/472三页平均67%<70%）
**保存范围：前 471 页（4710家）**

### 保温杯 thermospromo AI反思确定临界（★最新完整案例）
> 种子 thermospromo.com（促销保温杯公司）→ total:9998。B端买家=促销品/礼品商/饮具杯壶商/户外装备商/企业merch。
| 页 | AI反思匹配 | 状态 |
|----|----------|------|
| 900 | 7/10 | ✅ |
| 950 | 8/10 | ✅ |
| 965 | 8/10 | ✅ |
| **966** | **7/10** | **✅最后达标** |
| **967** | **3/10** | **❌跌破** |
| 968-999 | 1-5/10 | ❌ |

**★ 保温杯合理临界 = 第 966 页**（966页70%最后达标，967页30%跌破）→ **保存前966页（9660家）**

**AI反思匹配示例**：ZipSip(饮料配件制造商，v1 宽标准口径；v2 下属 OEM/拓品线——按 §一计数规则不进直采池)、Stan&Co(保温杯/水瓶)、SageTech Labs(激光雕刻定制饮具)、350Swag(促销品批发)、Merch'd(企业merch) = 匹配；纯服装/挂绳/奢侈品/医疗/宠物/CN = 不匹配。
