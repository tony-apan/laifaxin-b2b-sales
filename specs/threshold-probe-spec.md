# S4-A 临界点探测执行规范 v3.1

> 依据：RULES.md S4 行；CORE-POINTS.md 铁律 2/4/5、L155；specs/threshold-method.md；tools/finalize_audit.py 契约。
> **判据主从**：与 threshold-method 冲突时以 threshold-method 为准，本文件只做执行细则。

## 0. 唯一判据

| 项 | 定义 |
|---|---|
| 窗口 | **连续 5 页滑动平均**（每连续 5 页合计 matched/total ≥70%） |
| 达标带 | **已采样覆盖区**内、从第 1 页起所有连续 5 页窗口都 ≥70% 的最长前缀；未采样页标 UNKNOWN，**不得声称全带合格** |
| **临界页** | **达标带末页** = 首个 <70% 滑动窗口的**前一窗口末页**（= 该窗口起点 + 3；跌破即止，**不取跌破后的反弹窗口**，真源 threshold-method L81-83） |
| 单页读数 | 仅作披露与说明，**不得单独定界** |

依据：CORE-POINTS 铁律 2「正式边界用连续 5 页滑动平均」。

**覆盖声明**：RULES.md S4 行的「50 页跳」在本文件内被覆盖为「100 页跳」。依据=用户 2026-10-22 明示「100 页 1 跳，查看前后 3 页，直到后边低于 70%，然后往回」。执行时若与 RULES 冲突，以本条为准；RULES/INDEX 待同步修订。

## 1. 请求参数（固定）

POST /api/refine/company-list
headers: accesstoken, uid, Content-Type: application/json
body: keyword=<客户域名>, current=<页码>, pageSize=10, logic=and, sort=<平台默认排序，须记录原值>
filters=[{"property":"country_code","operator":"exclude","value":"","values":["CN","TW","HK","MO"],"valueType":"select"}]

- pageSize 固定 10（不传 422）；四区固定不得增减（RULES 铁律 0）
- 每页必须记录：current、queryId、返回条数、matched（达标家数）、total（实际返回数）、dailyUsed 前后值、emailsCount 逐条列表

## 2. 判定与双口径（定义，不得再靠外部文档）

判定唯一动作：读 **product-profile 的 ①产品名 ③用途 ④不适用**，问「**这家会不会买我们的产品**」。会→达标；不会/看不出→不达标。必须读 description，不得只看名称/role。

**判定不额外消耗次数**：一页 pageSize=10 的响应已含全部 10 家的 summary_zh，**必须一次性批量判完 10 家**（1 次页请求 = 10 家判定）。**禁止逐家调详情/联系方式类接口**——那才会计次并额外消耗额度。判定只写结论与理由片段，不新增请求。

**口径覆盖声明**：本节只定义判定动作；「谁买/谁不买」以 product-profile 为准。profile 未写清时先请用户确认，**禁止套用任何行业样例**（户外/猫粮/椰蓉都只是示例，不是通用判据）。

- 不再维护“严谨/宽松”两套行业口径；抽样只记录 matched/total 与逐条理由，客户线按 profile 的角色定义打标签
- 「有独立站」列表字段读不到 → UNKNOWN，不计入任何口径的加分

## 3. 采样与收敛（唯一流程）

### 3.1 粗筛
100 页一跳：1、101、201、301、401、501、601、701、801、901（10 跳）
每跳取连续 3 页（P-1、P、P+1）；**首跳 P=1 无第 0 页，只测 1–2 页（2 次）**，其余 9 跳各 3 页 → 共 **29 次**。只记抖点。

### 3.2 跌破不是边界：先做远端复测（2026-10-25 实测修正）
**首个 <70% 只是“疑似跌破”，不得直接定界。** 必须补测：
- 1.5 倍页（如 100 → 150）与 2 倍页（如 100 → 200）；
- 若 2 倍页仍 ≥70%，继续测 300/400/500 或末页，直到出现**连续两个远端窗口** <70%；
- 只有“首个跌破 + 远端复测仍不回升”才算边界；远端回升则把边界后移，原跌破点记为单页低谷。

> 反例（2026-10-25 皮筏艇实测）：100 页 50%，但 150 页 90%、200 页 80%、300 页 70%，真正持续跌破在 450 页。只测前 100 页就写“临界页=100”是错误方法。

### 3.2.1 跌破即停 + 往回收敛
远端复测确认不回升后，某段 <70% → 停。维护「最后已知 ≥70 窗口」L 与「首个 <70 窗口」H，在 [L,H] 间做**窗口二分**（每次实测一个 5 页窗口，复用已测页）：步长 50→25→10→5→1；停止条件=step1 且相邻两窗口一上一下；同侧耗尽→出口5 UNKNOWN

### 3.3 边界带加密（关键步骤，v3 缺失）
找到疑似边界后，**在边界处补测至连续 6 页**（相邻两批 3 页，或补 1 批 3 页），逐页得到 matched/total。
这 6 页用于：① 算所有连续 5 页滑动窗口；② 取**首个跌破窗口之前最后一个 ≥70% 窗口的末页**作临界页（从低页往高页扫描，遇首个 <70% 窗口即止；该窗口之后的所有反弹窗口**一律不得定界**，例：371-375=70%、375-379=74% 均为反弹）。

### 3.4 终止条件（四出口）
1. **找到边界**：从低页往高页扫描，**首个** <70% 的连续 5 页窗口，其前一窗口 ≥70% → 取前一窗口末页为临界页
2. **无达标区**：第 1–5 页窗口实测 <70%（首跳只测 1–2 页时须补测 3–5 页）→ UNKNOWN
3. **全库合格**：末页=ceil(total/10)，须**实测末页**且已采样窗口全 ≥70% → 报「已采样范围全合格 + 覆盖率」，不得由最后一点推断全库
4. **预算耗尽**：查看次数达 60 → 出「未测定 + 已测点 + UNKNOWN」报告（合法，不进 S5）
5. **同侧耗尽/覆盖不足**：窗口二分无法一上一下，或关键页未采样 → UNKNOWN + 覆盖率披露

### 3.5 尾页/空页
末页 <10 条按实际条数计；窗口需满 5 个有效页，不足 5 页 → UNKNOWN，不得定界；空页与 total 对账后判 UNKNOWN，**不得按 0% 进窗口**

## 4. 输出：四件套（v3.1 按 finalize_audit.py 契约重写）

### 4.1 用户报告（可 emoji，不得作为证据提交）
列：页 / 抽样家数 / 严谨达标率 / 宽松达标率 / 严谨标记 / 宽松标记
标记值：达标 / 跌破 / 未测；临界页分别标 🌟🌟（严谨）与 🌟（宽松），两临界页不在同一页时各占一行

- `50页`（字面无空格，写 "50 页" 不算）
- `三页平均`
- `逐页`

## 5. 本步骤边界（**不涉及邮箱/点数**）

S4-A **只产出两样东西**：

1. **临界页**（或边界带）
2. **池家数** N_pool = min(临界页 × 10, pool_total)

**明确不涉及**：邮箱数、e（邮箱/家）、E（可发封数）、p（点数/邮箱）、3000 封判定、contactMaxCount —— 这些全部属于 **S5**，在保存实测后计算。

- 列表响应里的 `emailsCount` 一律**不采集、不统计、不参与任何判定**
- 探测阶段不查点数、不查邮箱、不建保存计划
- 报告里不得出现「邮箱」「封数」「点数」相关列

## 6. 保存交接（S4-A → S5；邮箱/点数在 S5 计算）

- **字段拆名**：page_returned=每页实际返回条数；page_total=该页分母；pool_total=data.total（≤10000 截断值）
- Y = min(临界页 × 10, pool_total)；X = baseline（上次保存并集家数，来源 operation-record）；N_new = max(0, Y − X)；selectTotal = Y（累计前 Y 家，不是新增）
- **以下均为 S5 阶段计算，S4-A 不填**：E = N_new × e（e 来自 S5 保存后实测 contactSaveCount ÷ 家数）；P = ceil(E × p)
- 去重键：query_scope_key = 工作空间 + product/generation + selection + keyword + filters + logic + sort（RULES L189）
- E/P 见上（E=N_new×e，p 默认 1.5 点/邮箱，CORE-POINTS L65，带 version）；B=用户确认；P ≤ B 且 P ≤ max_points（来源/版本写明）；保存前查点数余额
- 保存参数：selectOption=front、**selectTotal=Y（累计前 Y 家，不是新增数）**、selectKeys=[]、contactMaxCount（固定值，须写明）
- 若已存在基线 X（同 scope 已保存）：selectTotal=Y，新增 N_new=Y−X 仅用于 E/P 估算；**同 query_scope_key 已有 attempt 时按 RULES:189 停止，不得减基线重发**
- **回读对账**（按 RULES L187-189）：
  - contactSaveCount（本次新增邮箱数）↔ E（邮箱数），不是 ↔ N_save
  - companySaveCount（=selectTotal，进度计数）**不得**当「全新增」证据
  - 偏差只作披露，不设硬 5% 阈值；偏差 >20% 记 UNKNOWN 并说明
- 保存失败处置：先 reconcile 再决定重发，不得盲目重存

## 7. 预算（单轮上限 = 60 次请求；其中连续采样 ≤51 次）

| 动作 | 次数 |
|---|---|
| 粗筛 9 跳×3 页 + 首跳 1 页×2 次（P=1 无第 0 页） | 29 |
| 回落窗口二分 5 档 × 最坏 5 页 | 25 |
| 边界带窗口二分（加密） | 3 |
| 复核（临界页前后各 1 + 复查 1） | 3 |
| **合计** | **60** |

**计数单位**：1 次 = 1 个页请求（返回 10 家）；判定本身不计次。严禁按公司计次，严禁逐家拉详情。

报告末尾必须写：本次查看 N 次（首测 X + 补测 Y + 复核 Z），N ≤ 60；超限本轮作废

## 8. 防偷懒（可机械核验）

1. 临界页必须是**窗口实测**得出，禁止「约/大概/估计/推算/趋势/应该/差不多/左右/近/保守取/按历史折算」给单值；允许区间，但区间端点必须各有实测页。
2. 表格列全所有已测页；未测写「未测」，不许省行。
3. 每页证据：page / returned（实际条数）/ matched / total / queryId / dailyUsed 前后值；判定理由取自该页 summary_zh 片段（≤20 字），不额外请求。
4. 每个结论附证据 id（run_id + 页号）。
5. **合法终态**最低工作量：粗筛 9 跳 + 首跳 2 页全跑完 + 每跳页级证据齐 + dailyUsed 前后值 + 请求清单 ≤60 条；不满足不得报「预算耗尽」。
6. 禁止用别案/旧数据补位；跨案例引用必须带 run_id。
7. 判定必须读描述并留理由片段（≤20 字）。
8. 异常：401/403/422/301 立即停并报 E_CONFIG（不计证据）；5xx/超时重试 ≤2；不得以异常为由跳过回落。
