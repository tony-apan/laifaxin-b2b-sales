# 检查清单（Checklists）

## ✅ 通用铁律（任何操作前）

- [ ] 操作前查过 lessons/ 先例？（踩过坑没有）
- [ ] 参数语义实测过？（不猜：views:[] / seqId / 标签ID）
- [ ] 批量操作先小批量验证数量？
- [ ] 判断标准写死？（用工具/规则表）

## ✅ 保存前（Search → Save）

- [ ] 已抽样查看前 1~5 页 + 末尾页
- [ ] **搜索锚已定**：小批量=客群 query_en 文本直存（无需域名）；扩量=域名锚（domain/similar-list 结果自带 domain 直接取，勿用公司名搜相似 L-45）；相似池 P1+P50 角色构成 >70% 买家才用（L-46）
- [ ] 本页精准度 ≥70%（中等默认；80/60 须用户指定，marketing-rules-2.0 §1）
- [ ] 已确定地域范围（排除中国区 CN/TW/HK/MO）
- [ ] 公司标签已想好（黄金公式(★已废,RULES铁律7:标签=客户群体中文名非我方产品)：语言-国家-产品-角色）
- [ ] 联系人标签与公司标签一致
- [ ] 邮箱类型：有效 + 未知
- [ ] 每客户保存数量（默认 3；存不到数据才按 3→6→9 升阶，每公司邮箱数裁决）
- [ ] 未滥用高级选项（职位/排除词慎用；排除4区 CN/TW/HK/MO 与"选择前N条"为例外必用，见铁律0/L-28/29）
- [ ] 点数充足（看预计消耗）

## ✅ 发信前（Marketing）

- [ ] 客户标签已打好（可批量加）
- [ ] 邮件模板已备好（AI 开发信生成）
- [ ] 发送渠道：优质发送通道（群发）
- [ ] 发信昵称已设置
- [ ] 计划时间按客户时区

## ✅ 智能跟进计划启动前（Sequence）

- [ ] 邮件追踪已开
- [ ] 发送上限已设（计划24h + 单域名2~10）
- [ ] 公司触发器已配（同公司多联系人策略）
- [ ] 未发送触发器已配（避免无效/黑名单）
- [ ] 模板多选（随机更自然）
- [ ] 后续邮件内容规划（不是只换标题）
- [ ] 计划已激活
- [ ] 已按标签添加客户

## ✅ 保存任务验证（Save 后）

- [ ] 保存任务记录：finished > 0
- [ ] 公司列表出现客户（带标签）
- [ ] 联系人列表出现邮箱（数量=设定值）
- [ ] 标签正确（公司/联系人各自体系）
