# 00 · 总流程全景（10 分钟速通）

> 来源：`https://www.laifa.xin/zhinan/quick-start-laifaxin-10min` + 官方指南

## 🎯 一句话主流程

**先找客户 → 筛掉不准 → 保存就打标签 → 建跟进计划 → 看效果跟回信**

跑通这条主线，开发流程就自动化起来了。

## 🗺️ 流程总览

```
[找客户] ──→ [筛客户] ──→ [存客户] ──→ [建计划] ──→ [看效果]
   │            │            │            │            │
 4种搜索       抽样+3种筛法  保存打标签    智能跟进     报告/回信
   │            │            │            │
 搜域名/推演/   ≥70%精准    自动去重      3~12轮自动
 提纯搜/找相似 才保存       不重复扣点    按时间发送
```

## 📌 关键决策点

### 1️⃣ 找客户：先判断"有没有种子客户"

| 你的情况 | 推荐方式 | 速度 | 准度 |
|---------|---------|------|------|
| 手里有 1 个目标客户网址 | ① 搜域名（找相似） | ⚡⚡⚡ | ⭐⭐⭐⭐⭐ |
| 只知道自己产品 | ② AI 推演 | ⚡⚡ | ⭐⭐⭐⭐ |
| 用常规词搜出来太杂 | ③ 提纯搜 | ⚡ | ⭐⭐⭐⭐ |
| 结果里发现 1 个极准客户 | ④ 找相似（滚雪球） | ⚡⚡⚡ | ⭐⭐⭐⭐⭐ |

### 2️⃣ 筛客户：抽样看"本页"精准度

- 抽查**前 1~5 页 + 末尾几页**，30 秒判断整体精准度
- **≥70% 是目标客户** → 可以保存
- <70% 有杂质 → 往前翻页找更准的范围 / 用 AI 评分
- ⚠️ 判断标准是"**本页**"，不是累计平均

### 3️⃣ 存客户：保存就打标签

- 保存设置建议：公司标签=客户群体名、联系人标签同、邮箱类型=有效+未知、保存数量 3~5、**新手不调高级选项**
- 系统**自动去重**，一个邮箱只扣一次点，放心分批存

### 4️⃣ 建计划：智能跟进（强推）

- 选**优质发送通道**（系统通道，不影响域名信誉）
- 3~12 轮自动跟进：第 1 步加进后 30 分钟 → 第 2 步 5 天后 → 第 3 步 15 天后 → 之后每 30 天一轮（总跨度约 10 个月）
- 客户回信 → 立刻人工接管

### 5️⃣ 看效果

- 邮件追踪（打开/点击/附件下载）
- 报告 + 邮件记录 + 操作日志 → 判断客户质量和模板效果

## ⚠️ 新手避坑（最常翻车）

| 坑 | 后果 | 怎么避 |
|----|------|--------|
| 用错"产品词" | 搜出来的是同行不是客户 | 搜客户的产品词（金主），不搜自己服务词（同行） |
| 一上来全选→AI评分 | 瞬间扣几百到几千点 | 先抽查，确认精准度再评 |
| 一上来全选保存 | 浪费点数和邮件资源 | 抽样 ≥70% 才保存 |
| 忽略发信昵称/发送上限 | 客户看到不自然/过度触达 | 高级规则里设置 |
