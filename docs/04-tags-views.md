# 04 · 标签与视图（给客户贴名片 + 一键筛人群）

> 来源：`https://doc.laifa.xin/zhinan/contacts-tags-views.html`

## 🎯 一句话记忆

| 工具 | 一句话 | 例子 |
|------|--------|------|
| 🏷️ 标签 (Tags) | 给客户贴**静态名片**——描述"他是谁" | 英语-美国-皮筏艇-经销商 |
| 👀 视图 (Views) | 创建**动态筛选器**——解决"要找谁" | "所有美国的皮筏艇经销商" |

> 🔑 标签告诉你"他是谁？" → 视图帮你实现"要找谁？"

## 🗺️ 整体协同：标签 → 视图 → 邮件序列

```
标签（静态名片）→ 视图（动态筛选）→ 邮件序列（自动营销）
   客户画像          找一批人/排除一批人      持续的自动化营销
```

## 一、玩转客户标签（为客户精准画像）

### 1️⃣ 标签"黄金公式"（强烈建议统一格式）

> ⚠️ **本项目命名规则已改（2026-08-30，RULES 铁律7/8）**：标签 = **客户群体中文名**（如 `水上运动行业客户`），内部命名一律中文、记录一律 `id(名称)` 成对。下方"语言-国家-产品-角色"公式是官方教程原版，仅作背景参考——实际打标签以 `RULES.md` 铁律7 为准。

**语言 - 国家 - 产品/行业 - 供应链角色**

| 序号 | 你的业务 | 客户群体 | 推荐标签 |
|------|---------|---------|---------|
| 1 | CNC 机加工 | 德国汽车工厂 | 德语-德国-汽车配件-工厂 |
| 2 | 皮筏艇 | 美国水上用品经销商 | 英语-美国-皮筏艇-经销商 |
| 3 | 工程设备 | 巴西工程设备进口商 | 葡语-巴西-工程设备-进口商 |

**顺序为什么这样排**：
- **语言**最前 → 按语种快速筛模板（所有"德语"客户用同一套德语开发信）
- **国家**次之 → 按地域做时区与节日营销
- **产品/角色**最后 → 适合客群细分，不是日常筛选第一入口

### 2️⃣ 标签分组：客户 / 意向 / 风险

| 分组 | 用途 | 标签示例 |
|------|------|---------|
| 客户（核心） | 描述重要属性，按黄金公式 | 英语-美国-工程设备-进口商 |
| 意向 | 标记跟进状态（温度） | 💬询盘 / 📦寄样 / 💰成交 |
| 风险 | 标记需要排除的人 | ❌同行 / 🚫退订 / ⛔其他 |

## 二、用好联系人视图（智能筛选）

**核心价值**：标签是静态名片，视图是**动态筛选器**。最大用途：快速找一批人，或群发时快速排除一批人。**一次设置，永久复用**。

### 1️⃣ 新建和管理视图
- 联系人管理 → 右上角「创建视图」
- 常用视图可**固定**在列表上方，拖动排序，把最重要的设为默认

### 2️⃣ 设置筛选条件（并且 / 或者）

| 逻辑 | 说明 | 结果 |
|------|------|------|
| 并且 (and) | 满足所有条件 | 条件更严 → 结果更少 |
| 或者 (or) | 满足任意一个条件 | 条件更宽 → 结果更多 |

### 3️⃣ 4 个超实用视图案例

**① 意向客户排除视图**（发开发信时自动排除已有进展的）
- 条件：标签 任意包含 💬询盘/📦寄样/💰成交；逻辑：或者

**② 风险客户排除视图**（群发时排除有风险的，保护发件箱信誉）
- 条件：标签 任意包含 ❌同行/🚫退订/⛔其他；逻辑：或者

**③ 不发邮箱排除视图**（自动筛掉不想营销的邮箱）
- 邮箱开头是 hr@; noreply@; marketing@; jobs@; customerservice@
- 邮箱结尾是 qq.com; 163.com; aliyun.com; 263.com; 88.com; 188.com
- 邮箱结尾是 .cn; .tw; .hk; .in
- 邮箱包含 .gov; .org; .edu
- 逻辑：或者（命中任一就排除）

**④ 已读客户跟进视图**（筛出感兴趣的"温"客户高频跟进）
- 条件一：阅读次数 大于 0；条件二：标签 任意包含 英语-美国-工程设备-经销商；逻辑：并且

## 三、实战演练（理论用起来）

**目标**：启动邮件序列，向所有英语区域的皮筏艇经销商自动发开发信

1. **确认标签**：确保客户打了正确标签（英语-美国-皮筏艇-经销商 / 英语-英国-皮筏艇-经销商）
2. **确认视图**：按标签筛选目标客户
3. **创建邮件序列**：按标签批量加入智能跟进计划

## 🔬 实测接口（API）

- 标签列表：`POST /api/contacts/tags-list` `{"type":"company"}`（公司标签）/ `{"type":"contacts"}`（联系人标签）
- 创建标签：`POST /api/contacts/tags-add` `{"name":"...","type":"..."}`
- 视图列表：`POST /api/views/views-list` `{"type":"dbSearchCompany"}` / `{"type":"contacts"}`
- ⚠️ 公司标签和联系人标签是**两个独立体系**（company 18个 vs contacts 159个），保存任务里 companyTags/contactTags 要分别用对应体系的标签 ID
