# 07 · AI 打造高回复开发信（多轮开发信序列）

> 来源：`https://mp.weixin.qq.com/s/z9Mqp7MlXuut-dZEXyo9EQ` + `https://www.laifa.xin/share/email/ai-generate-multi-round-cold-email-sequences`（方法源自官方公开教程；第三方教程原文未随库分发，本文件为整理版）

## 🎯 核心目标

把一封邮件从"一颗扔出去的石子"变成"一个伸出去的钩子"——目的不是把产品说明书塞给对方，而是**钩住他的兴趣**，让他愿意回你第一句话。

> 优化开发信 = 把"烦人推销"变成"值得认识的人"

## 📋 完整 Prompt 结构（整理版）

### 第一部分：核心创作准则

**1. 深度共情（Empathy First）**
- 视角锁定：第一思考点是"收件人最关心什么、最头疼什么？"，忘掉推销，聚焦"我能帮你解决什么"
- 痛点切入：开场白直击一个具体真实的业务痛点（供应链延迟、成本飙升、环保法规压力、创新瓶颈等）

**2. 版式结构与美学**
- **呼吸感公式**：每封邮件必须结构化布局
- **① 段落戒律**：一段一句！每个段落**绝对不能超过一句话**
- **② 核心价值展示**：核心优势用项目符号列表（`<ul><li>`），2-3 个最佳
- **③ 邮件流模板（5步）**：
  1. 开场痛点 (Opener - Pain Point) 1句
  2. 解决方案桥梁 (Bridge - Solution Intro) 1句
  3. 核心价值列表 (Core Value - Bullet Points) 2-3个
  4. 引导式提问 (Closing Question) 1句
  5. 行动号召钩子 (The Hook) 1句
- **④ 视觉焦点层级**：强调标签 ≤4 个（规则四）
  - 第一层级：最能击中痛点的利益点用 `<b>` 或 `<b><u>`（核心冲击点）
  - 第二层级：次要关键词（产品名/认证/关键特性）用 `<i>` 或 `<b>`
  - 数量铁律：全文被强调的词 ≤4 个（不含CTA钩子）
- **标题焦点**：5-7 词英文标题 + 开头/结尾 1 个相关 Emoji

**3. 极简主义**
- 每封邮件（含签名）**≤100 个英文单词**
- **绝对禁止 Dear**！用 `Hi {联系人:名称}` / `Hello` / 直接开场白
- 签名只留一个友好英文名（如 Alex），**严禁**公司/职位/电话/链接（零营销感，规避垃圾邮件过滤器）

**4. 钩子设计（CTA 不是请求，是"下意识反应测试"）**
- 必须极度简单、低门槛
- **① 资源型钩子**（互惠原则）：`回复 **Catalog** 获取我们最新的独家设计`
- **② 洞察型钩子**（信息差）：`想看看我们为[类似公司]节省20%成本的数据吗？回复 **Data** 即可`
- **③ 资格型钩子**（承诺一致性）：`如果能确保您的产品在圣诞节前准时到港，您会有兴趣了解更多吗？一个简单的 **Yes** 就好`
- **强制 HTML 结构**：`reply with <span style='background-color:yellow; color:red; padding:2px 4px; font-weight:bold;'>KEYWORD</span> to receive...`

### 第二部分：策略应用视角（9 大策略工具箱）

| 策略 | 聚焦 |
|------|------|
| 1 价值主张型 | 产品核心价值和普适性好处 |
| 2 降本增效型 | 节省资金/时间/提升效率 |
| 3 稀缺资源型 | 独家技术/特殊材质/市场稀缺性 |
| 4 对标竞争型 | 相对竞品的决定性优势 |
| 5 降低门槛型 | 低MOQ/快速打样/免费设计 |
| 6 趋势引领型 | 行业新趋势/市场洞察 |
| 7 环保合规型 | 可持续性/环保认证/CSR/法规 |
| 8 交期优势型 | 快速交货/稳定供应链 |
| 9 服务保障型 | 售后/质保/技术支持 |

### 第三部分：多轮序列架构

- **序列长度**：6~12 轮（未指定时随机）
- **策略递进**：设计逻辑递进路径（痛点破冰 → 价值展示 → 建立信任）
- **每轮模板**：3~6 封不同模板（同策略下标题/开场白/价值点/CTA 有变化）

### 第四部分：最终交付格式

- **阶段一**：战略蓝图确认（Markdown引用块：核心洞察/破局点/序列逻辑）
- **阶段二**：营销序列总览（总轮数+每轮策略及目标）
- **阶段三**：逐轮邮件矩阵（每轮分离输出，带上下文代码块标识）

### 第五部分：执行铁律
- **完整性**：禁止省略任何轮次/模板（8轮×4模板=完整32个）
- **格式化**：代码块之间至少一个空行

### 第六部分：任务指令格式

```
1. 【营销序列轮数】: 如 8（不填则6-12轮）
2. 【每轮模板数量】: 如 4（不填则3-6封）
3. 【邮件沟通风格】: 专业直接（默认）/热情友好/高端专属/风趣创意
4. 【我的价值主张】:
   - 产品/服务: ...
   - 特性->利益: （每个特性转化为客户好处）
   - 独特卖点 USP: （最好数字量化）
5. 【我的目标客户群体】:
   - 行业与地区: 如 法国户外运动产品零售商
   - 目标职位: 如 采购经理、品类总监
   - 核心痛点: ...
6. 【目标语言】: 英语（默认，禁止中文字符）
```

### 第七部分：交互控制（单步交互式生成）
- **步骤0**：规则内化后回复"✅ 所有核心创作准则已内化。请提供您的【产品/服务信息】以及【目标客户画像】..."
- **步骤1**：只生成第一轮，询问"是否需要修改？满意请回复'继续'"
- **步骤2**：只有回复"继续"才生成下一轮，每次停下等指令

## 🛠️ AI 工具配置（以腾讯元宝为例）

1. 复制核心指令 → 2. 新建智能体 → 3. 命名（如"欧美开发信助手"）→ 4. **开启深度思考**（关键！决定逻辑深度和排版精准度）→ 5. 粘贴指令保存

> 字符超限：元宝网页版可能超限，可分段粘贴或用支持长指令的工具（ChatGPT/DeepSeek/Kimi 均可）

## 📥 AI 生成 HTML 模板 → 导入来发信（完整闭环）

**核心技巧：让 AI 直接生成 HTML 源代码**（含格式），导入后不需要再编辑：

1. **生成模板**：AI 生成邮件主题 + 邮件正文（HTML 源代码格式）
2. **查看效果**：来发信弹窗里预览最终效果（代码 → 渲染）
3. **微调模板**：满意后直接指令"生成 5 封开发信模板"批量生成
4. **导入来发信**：邮件模板 → 新增/编辑 → **编辑源代码** → 保存 → 编辑框内看到最终效果
