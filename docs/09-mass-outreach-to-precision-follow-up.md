# 广撒网获询盘 + 精准背调跟进

> **一句话**：群发和精发不是二选一。群发负责低成本筛出“谁有反应”，询盘后再把人工时间集中到少数有信号的客户身上，做背调、定制回复和长期跟进。

## 1. 两个引擎，各做一半

| 阶段 | 广撒网引擎 | 精准跟进引擎 |
|---|---|---|
| 目标 | 从几百到几千家相关买家中筛出询盘信号 | 评估询盘有效性、优先级和采购时点，把合适的机会推进到样品、报价和订单 |
| 做法 | 客群搜索、批量保存、模板群发、12 轮自动跟进 | 公司背调、联系人角色核实、定制回复、多渠道长期培育 |
| 自动化程度 | 高，系统承担重复劳动 | 低，业务员人工判断和沟通 |
| 人工该花在哪 | 只做客群/模板/序列确认 | 只花在回复过、有业务信号的人身上 |

正确漏斗：

```text
广撒网批量触达
  → 收到回复/询盘信号
  → 立即打“询盘”固定标签，停止自动群发
  → 公司与联系人背调
  → A/B/C/D 意向分级
  → 邮件 + WhatsApp + 商务社媒 + 电话长期跟进
  → 样品 / 报价 / 谈判 / 成交或流失
```

## 2. 算一笔账

> **口径说明**：以下数字来自用户提供的运营估算与本账号成本口径，不代表所有平台、所有行业，也不承诺回复或成交。

| 项目 | 运营估算 |
|---|---:|
| 1000 封发送成本 | 约 7 元 |
| 3000 封发送成本 | 约 21 元 |
| 单封成本 | 约 0.007 元 |
| 一个人最低单日人工成本 | 约 200 元 |
| 纯手工精准开发量 | 一天深入研究 1~2 家已属高投入；很多天可能没有回复 |

> ⚠️ **此表只算"发送通道"成本，不是全部投入**。完整投入 = 发送 + 保存邮箱点数/账号套餐 + 人工（背调、定制回复、跟进）。1000 封约 7 元仅指发送通道；拿"21 元 vs 一条询盘"衡量值不值时，请把点数与人工一并算进去。

在这个口径下，3000 封的直接发送成本约 21 元。如果能筛出 **1 个经背调后进入 A/B 级的有效询盘**，说明用很低的直接成本找到了一条值得投入人工的线索。注意：

- 询盘本身没有收入，不能证明已经回本；最终是否覆盖成本取决于成交毛利与完整运营成本。
- 询盘不等于订单；后续仍有样品、报价、沟通和时间成本。
- 成交取决于产品匹配、价格、交期、认证、服务和跟进能力。
- 群发的价值是把昂贵人工从“无回应的陌生公司”移到“已经回复的人”。

## 3. 为什么询盘来了，对方又不回？

很多询盘只是轻微信号：

1. 随口问价，暂时没有真实项目。
2. 同时向很多供应商比价。
3. 拿你的报价去压现有供应商。
4. 项目延期、预算未批或采购周期还没到。
5. 回复者不是决策人，只负责收集资料。
6. 同行套资料、学生调研、求职或无关回复。
7. 真有需求，但你的第一次回复太泛、太慢或没有回答关键问题。

所以询盘之后不能只发一份通用报价单然后等待。必须先背调，再分级，再安排后续动作。

## 4. 询盘处理 SOP

### Q1：立即停止自动群发

- 人或 AI 助手发现回复后，必须立即给联系人打账号级固定标签 **“询盘”**。当前系统不会自动识别回复并替你打标签。
- “询盘”已在邮件序列的 notSentTags 中；**只有标签实际打上后**，后续邮件轮次才会停止。
- 如果客户明确退订、拒绝或要求不再联系，改打 **“不发”** 标签并停止所有渠道触达。

### Q2：登记询盘

至少记录：

- 时间、来源、公司、联系人、邮箱、域名、国家；
- 所属客群、触发模板 id、轮次与主题；
- 客户回复原文、核心问题、当前状态、下一步动作；
- WhatsApp、电话、LinkedIn 等公开商务渠道（若有）。

### Q3：公司与联系人背调

核实七项：

1. 官网是否真实经营相关产品；
2. 对方是品牌商、批发商、零售商、集成商还是终端用户；
3. 公司规模、分支机构、成立时间与主要市场；
4. 采购逻辑：OEM、转售、配套采购、项目采购或终端自用；
5. 现有产品与你的规格、价格带、认证是否匹配；
6. 回复者是否是 Buyer、Purchasing Manager、Owner 等决策角色；
7. CRM/历史档案里是否已有同事跟进，避免撞单。

### Q4：意向分级

| 级别 | 判断 | 处理 |
|---|---|---|
| **A 高意向** | 规格、数量、交期、项目明确；公司与角色都匹配 | 尽快人工回复，给针对性报价/样品/技术资料，并预约电话或视频会议 |
| **B 中意向** | 公司匹配，但只要目录、价格表或需求模糊 | 精选 2~3 款，不丢全套大附件；追问用途、数量、市场、目标价和时间 |
| **C 远期/低意向** | 暂无预算、项目延期、只说保持联系 | 转长期培育，低频发新品、案例、行业信息，不高频催促 |
| **D 无效/拒绝** | 退订、拒绝、同行套价、学生/求职/无关 | 打“不发”标签，立即停止所有营销触达 |

### Q5：多渠道长期跟进

| 渠道 | 适合做什么 | 使用边界 |
|---|---|---|
| 邮件 | 报价、规格、图纸、样品、合同，正式留档 | 主渠道；仍须按目标市场、收件主体类型、名单来源和拒收记录核验适用规则；不得隐藏发送主体，并须提供可用的退出方式 |
| WhatsApp | 已建立联系后的简短确认、样品进度、紧急提醒 | **仅在客户已经明确同意通过 WhatsApp 接收商务沟通后使用**；主动消息还应遵守 [WhatsApp Business Messaging Policy](https://business.whatsapp.com/policy) 的模板、窗口和退订规则。公开号码本身不等于许可 |
| LinkedIn/商务社媒 | 核实角色、关注公司动态、长期建立熟悉度 | 只用公开职业身份；站内联系须遵守平台规则和客户已表达的拒绝记录，不拼凑私人账号 |
| 电话 | A 级急单、重大规格确认、已建立关系后的预约沟通 | 每个市场单独核验：适用法律、国家/行业拒呼登记、内部不联系记录；通话时说明来电主体和销售目的，显示可回拨号码，对方要求时提供有效联系方式，并在当地工作时间联系。英国示例见 [ICO 电话营销指南](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guide-to-pecr/electronic-and-telephone-marketing/telephone-marketing/)，不可直接套用到其他国家 |

## 5. 建议节奏

- A 级：尽快回复；1~2 天内推进下一步，必要时电话/视频沟通。
- B 级：先给精选资料并提出 2~3 个具体问题；2~3 天后跟进。
- C 级：3~4 周一次低频培育；有新品、案例、促销或采购季节点再联系。
- D 级：立即停止，不再换渠道追击。

节奏只是建议，应根据时区、行业采购周期和客户明确要求调整。

## 6. 常见误区

- **询盘=订单**：错误。询盘只是信号，需要背调和分级。
- **询盘后继续自动群发**：错误。立即打“询盘”标签停发。
- **一上来发几十兆目录**：错误。先精选客户最可能要的 2~3 款。
- **没回就不断催**：错误。先判断项目周期，再安排低频长期培育。
- **换 WhatsApp/电话继续骚扰拒绝者**：错误。明确拒绝即全渠道停止。
- **只做群发，不做背调**：只完成了一半；询盘来了不会转化。
- **只做精准开发，不铺量**：人工成本全部花在还没释放信号的陌生人身上。

## 7. 每日核实清单

- [ ] 新回复是否全部登记并打“询盘”标签停发？
- [ ] 明确拒绝者是否打“不发”标签并停止所有渠道？
- [ ] 是否核实官网、主营、规模、市场、采购逻辑和联系人角色？
- [ ] 是否完成 A/B/C/D 分级？
- [ ] A/B 级是否有明确下一步、负责人和时间？
- [ ] WhatsApp 是否已有明确接收许可？电话是否通过目标市场拒呼/合规检查？社媒是否仅用公开商务身份？
- [ ] C 级是否进入长期培育计划，而不是高频催促？
- [ ] 本周询盘是否反哺客群、种子和模板优化？

## 8. 系统边界

本系统负责：批量找客户、批量触达、按计划发送邮件，以及在联系人已被人工/AI 助手打上“询盘”或“不发”标签后停止后续邮件轮次。当前系统**不自动识别回复、不自动打标签，也不自动拦截 WhatsApp/社媒/电话**。

业务员负责：询盘背调、意向判断、定制回复、报价、样品、谈判、多渠道长期跟进与成交。

**系统降低“找信号”的成本，不替代业务员完成成交。**

### 这套方法的隐含前提（先看你的产品在不在前提里）

整套漏斗（批量找买家 → 广撒网 → 等询盘）默认一个前提：**目标买家是可批量检索的长尾 B2B——买家够多、有公开邮箱/询价邮件文化、采购与询盘响应以天~周计**。前提成立，12 轮自动跟进才有意义；前提不成立，漏斗会空转（详见 [specs/product-fit.md](../specs/product-fit.md) 的三档判定）：

- **大宗原料 / 长周期项目制设备 / 需招标、认证、入库入围 / 好几年才采购一次 / 全市场买家屈指可数**的品类——冷邮件基本不会带来询盘，广撒网只能低成本摸底，不能替代展会、渠道或关键客户开发。
- **工业标准件、需要规格认证但买家有分层**的品类（如步进电机）——适合，但要主打分销/集成/贸易商等渠道层，终端大厂走 OEM/拓品线单列长期积累；别拿同行制造商当种子（L-46）。
- 12 步节奏（30 分/5/15/30 天 ×9）按**快周期品类**设计；客群采购周期以季~年计时，请调低轮次或转人工/低频培育，别用月级自动跟进反复打扰周期外的买家。
