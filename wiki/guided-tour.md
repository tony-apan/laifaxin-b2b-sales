# 🧭 新手导览：从一个产品到一批询盘

> 假设你卖**猫粮**（或任何外贸产品），第一次用来发信。跟着我走，10 分钟建立全局，再一步步跑通。

## 第 0 步：建立全局（3 分钟）

记住一句话：**先找客户 → 筛掉不准 → 保存打标签 → 建跟进计划 → 看效果跟回信**。

这 5 步是一条流水线。你不需要一开始就研究所有功能，跑通主线，再优化。

## 第 1 步：让 AI 帮你想客群（3 分钟）

你只有一个产品（猫粮），没有客户网址？用 **AI 推演**：

1. 打开来发信 → **搜客引擎 → AI 数据库**
2. 点搜索框右侧的 **AI 推演**
3. 输入"猫粮" → 点 **AI 智能生成**
4. 系统给你 **8 个目标客群**，每个都有推荐理由和英文搜索词：
   - 宠物食品与用品专业分销商（最直接买家）
   - 社区宠物用品独立零售商
   - 综合宠物诊疗与外科医院
   - 主题猫咖啡馆...
5. 选最匹配的客群 → 点 **立即查看** → 系统自动搜索

> 💡 客群不准？去 **方案库** 编辑产品方案，写越详细，推演越准。修改后重新推演。

## 第 2 步：找客户（10 分钟）

### 路线 A：有种子客户 → 搜域名（⭐⭐ 最准）
1. AI 数据库搜索框**输入客户网址**（如 saturnrafts.com）
2. 点搜索 → **搜出上万个结果**，第一个是这家公司，下边全是它的同行
3. 这就是"找相似"——精准同行

### 路线 B：没种子 → 关键词搜
- 搜**客户的产品词**（如 cat food manufacturer）→ 找到的是金主
- 别搜自己的服务词（如 pet food production）→ 找到的是同行
- 搜出来太杂？用**提纯搜**：从精准客户的业务描述里提炼英文词再搜

## 第 3 步：筛掉不准的（5 分钟）

1. **抽样**：看前 1~5 页 + 末尾几页，判断"本页"精准度
2. **≥70% 是目标客户**（★现行默认；教程写≥80%）→ 可以保存；<70% → 往前翻页或用 AI 评分
3. **排除中国区**：筛选 → 国家或地区 → 不包含 → 勾中国/台湾/香港/澳门 → 应用筛选

> 也可以直接用 AI 评分：勾选客户 → 点 AI 评分 → 系统给 0~100 匹配分

## 第 4 步：保存打标签（5 分钟）

1. 结果页随机勾选 1 个客户 → 点**高级** → **选择前 N 条数据**（如 1940 = 194页）
2. 点**保存联系人** → 弹窗：
   - 公司标签：`英语-猫粮-宠物食品分销商`（黄金公式：语言-国家-产品-角色）
   - 联系人标签：保持一致
   - 邮箱验证结果：勾**有效邮箱** + **未知邮箱**
   - 每家公司保存多少个：**3**
   - **别碰高级选项**
3. 点**确认保存** → 系统自动去重建档，标签自动打上

## 第 5 步：写开发信模板（用 AI，30 分钟）

1. 用 **多轮开发信 Prompt 方法**（见 docs/07）配置 AI 助手（元宝/ChatGPT/DeepSeek）
2. 提供：产品信息 + 目标客户画像 → AI 逐轮生成 6~12 轮开发信（每轮 3~6 封）
3. 让 AI 直接生成 **HTML 源码** → 导入来发信邮件模板（编辑源代码 → 保存）
4. 模板要点：一段一句、≤100词、禁 Dear、签名零营销感、钩子用 KEYWORD 高亮

## 第 6 步：建智能跟进计划（10 分钟）

1. 邮件营销 → **邮件序列** → **+ 序列**
2. 发送渠道选 **优质发送通道**（多域名/IP切换不怕封号）
3. 计划名称写客户群体（如"猫粮-宠物食品分销商-自动跟进"）
4. 添加步骤：第1轮立即发 → 30天后未回复发第2轮 → ...（3~12轮）
   - 每轮选模板（可多选随机）
   - 第1封讲身份产品、第2封价值案例、第3封给资料/报价
5. **高级规则**：发信昵称 + 发送上限（计划24h + 单域名2~10）+ 触发器
6. 激活计划 → **按标签批量添加客户**

## 第 7 步：看效果（持续）

- 邮件追踪：打开/点击/附件下载实时看
- 客户回信 → **立刻人工接管**（1-on-1，用自有邮箱）
- 看报告判断：客户质量（回复率）+ 模板效果（阅读率）

---

## 🎯 一句话总结

**AI 推演定客群 → 搜域名/提纯搜找金主 → 抽样筛到 ≥80% → 保存打标签 → AI 写多轮模板 → 智能跟进自动发 → 回信人工跟进**

跑通这条线，你的询盘就开始自动进收件箱了。
