# runs/ 导航卡（公开仓）

> **公开仓仅含 `runs/_template/`（新案例起始模板）**；各运营方运行档案（`runs/<运营方>/<产品>/` 下的 operation-record / reflection / evidence / verify-* 等）与 `db/runs.tsv`、`db/segments.tsv` 等运行数据表为**运营方本地数据，不入库**（模板见 `runs/_template/README.md`）。
>
> 新案例起步：复制 `runs/_template/` → 按 `RULES.md` 状态机 S0-S12 执行 → 每步结果写入 `runs/<运营方>/<产品>/` 对应文件（本地留存）。

| 子目录 | 放什么 | 什么时候进 |
|---|---|---|
| `_template/` | 新案例起始模板：operation-record、reflection、segments 等骨架文件 | 开新案例、查运行档案该写哪些文件时 |
