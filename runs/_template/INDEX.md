# runs/_template 索引
> 一句话：新公司/新产品从这里复制的运行档案模板；初始化项目前读。

## 子目录

| 子目录 | 说明 | 什么时候进 |
|---|---|---|
| segments/ | 客群档模板与字段字典，见 segments/INDEX.md | 需要新建或读取客群档时 |

## 文件

| 文件 | 说明 | 什么时候读 |
|---|---|---|
| README.md | 模板用法、目录规则与命名铁律 | 新建项目第一步 |
| operation-record.md | 流程核查记录模板（status/next_state） | 每步更新状态时 |
| product-profile.md | 产品知识档案机读模板（8 字段/版本/hash） | S0a 建档时 |
| reflection.md | 项目复盘模板 | 收尾或旁观者审查时 |
| segments.md | 客群索引生成物模板 | 汇总多客群时 |
| templates.md | 模板登记与效果表模板 | 建完模板后登记时 |
| audit-manifest.json | S4 审计绑定清单模板 | 审计收口时 |
| verification-manifest.json | S11 四证据绑定模板 | 终检收口时 |
| compliance-check.json | S12 五项合规证据模板 | 激活前 |
| recovery-manifest.json | ERROR 受控恢复清单模板 | 异常恢复时 |
| evidence.json | 项目证据汇总模板 | S11/S12 收证据时 |
| inquiries.tsv | 询盘记录模板 | 收到询盘时 |
| ops-log.tsv | 操作日志模板 | 每次操作后 |
| website-profile-candidate.json | 网站资料候选模板 | 启用网站资料增强时 |
| website-profile-patch.json | 网站资料批准补丁模板 | 导入网站资料时 |
