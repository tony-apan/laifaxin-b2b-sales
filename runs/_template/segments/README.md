# 客群档字段字典（★防歧义唯一标准——其他 AI 照此读写，禁止猜字段含义）

> **每个客群一档**（铁律 7d：一客群一标签一计划）。本目录各档=唯一真源；`../segments.md` 与本地索引是生成物。

| 字段 | 定义 | 格式/合法例 | 非法例 |
|------|------|------------|--------|
| segment_id | 产品内唯一编号，永不复用 | `S01`..`S99` | 复用已归档编号；带语言(S01-英) |
| segment_name | 客群名=标签名 | `语言-行业-角色`：`英语-水上运动-经销商` | 含产品名(`英语-皮筏艇-经销商`)；纯英文 |
| inf_id | 推理API返回的segment标识 | 原样记录 | 改写 |
| lang | 语言/市场 | `英语(全球)`/`西语(拉美)` | 空 |
| query_en | 英文搜索词（直接做搜索keyword用） | 母语采购商会输入的完整短语 | 中文；单词堆砌 |
| desc_en | 英文长描述（query_en 的完整版） | 1-3句 | 空 |
| 客群确认 | 第一步：是真实独立客群吗 | ✅+一句语义判据 / ❌+并入哪个 | 跳过此步直接评分 |
| 产能 | 潜客量级评分1-5 | 依据=query_total+AI评估，须写数字 | 拍脑袋无据 |
| 询盘快/周期短/邮箱 | 评分1-5(5最优) | 同上 | — |
| 竞争 | **1=竞争小(有利)→5=竞争激烈(不利)**；加权时取 **6-x 反向** | 竞争=2 → 加权按4计 | 方向未定义裸用 |
| segment_name/platform_name | platform_name=平台推理中文名(留档对账)；**标签名**才用 `语言-行业-角色` | 档名可用平台中文名 | 把平台名直接当标签名 |
| X编号 | 跳过档按 **API 返回顺序** 编 X01,X02…（与S轨并行,永不复用） | X01=列表第一个跳过档 | 文件与索引两套编号 |
| 推荐序 | 产品内排序 | `#N`（由五维+客群确认重算，手改无效） | 手填 |
| state | 状态机 | `待搜→搜索中→已保存/跳过(原因)/已合并执行(legacy)` | 自创状态 |
| seeds 表 | 种子尝试（多个都留） | 表：种子网址/total/临界页/保存N/单家/邮箱数/结果/时间 | 覆盖旧种子行 |
| company_tag/contact_tag | 标签 | `id(名称)` 成对 | 只写id |
| created/updated | 时间 | `YYYY-MM-DD HH:MM` | — |

**状态转移表**：待搜→搜索中（开始audit）→已保存（save finished+标签>0）｜跳过(写原因，可回到待搜)｜已合并执行(legacy，仅旧数据)

## ★多客群归属（铁律 7d）

每个客群档必须能回答"这个客群用哪个标签、哪套模板、哪条序列"——三列齐全：

| 归属 | 字段 | 要求 |
|------|------|------|
| 标签 | `company_tag` / `contact_tag` | 本客群**专属**一对，`id(名称)` 成对；禁止与其他客群共用 |
| 模板 | 模板批次前缀/后缀 | 本客群**专属** 120 封；前缀带客群标识 |
| 序列 | 序列名+id | 本客群**专属**一条；名字带客群档位后缀 |

**混存的后果**（真实案例）：多个客群共用一个标签+一套话术 → 不同采购需求打同一套痛点 → 效果打折；且 `threshold-method` 要求直采/OEM/拓品分线计数，合并标签会让制造商被打进经销商池、收错话术。
